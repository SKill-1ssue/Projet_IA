# TaskFlow - Application To-Do Liste

Application de gestion de tâches développée en HTML, CSS et JavaScript pur (sans framework ni bibliothèque externe).

## Fonctionnalités

- **US01** : Créer une tâche
- **US02** : Modifier une tâche
- **US03** : Supprimer une tâche
- **US04** : Marquer une tâche comme terminée
- **US05** : Consulter toutes ses tâches

Ouvrir le fichier `index.html` dans un navigateur web.
